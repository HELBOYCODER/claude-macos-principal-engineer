# Claude macOS Principal Engineer

A production-focused Claude Code plugin/skill for expert macOS software engineering.

## Capabilities

- Swift / SwiftUI / AppKit
- Xcode / Swift Package Manager
- macOS system APIs
- Network.framework / Network Extension
- concurrency and performance
- security, sandboxing and entitlements
- code signing and notarization
- Apple Silicon and Universal binaries
- debugging and testing
- Android/Linux to macOS porting

## Structure

```
.claude-plugin/plugin.json
skills/macos-principal-engineer/SKILL.md
references/
```

## Claude Code

Install/use this repository as a Claude Code plugin source. The skill is
automatically available when the plugin is enabled.
